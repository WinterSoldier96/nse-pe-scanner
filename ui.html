Finds NSE stocks whose share price has run ahead of their profits, from the exchange's own daily PE ratio files and bhavcopies. Run the steps in order; the first time, start with the quick test.

Run sheet

    Quick test

    Downloads the last 7 trading sessions. Takes about a minute and confirms NSE is answering.

  2. 2

    Download everything

    Every session since 30-Apr-2024. Files already on this computer are skipped.

  3. 3

    Check the data

    Each session should have both files, open cleanly and carry a normal number of stocks.

  4. 4

    Run the scanner

    Measures every stock's P/E change since its low and runs the fair test. About two minutes.
